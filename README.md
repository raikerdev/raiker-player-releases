# RaikerXV Player — versiones

Instaladores de **RaikerXV Player**, un reproductor de música basado en [NewAmp](https://github.com/Evilander/newamp) (licencia MIT, © 2026 NewAmp contributors).

- Descarga el `RaikerXV-Player-X.Y.Z-setup.exe` de la última versión (se instala para tu usuario, sin permisos de administrador).
- La app instalada avisa sola cuando hay una versión nueva.
